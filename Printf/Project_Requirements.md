**ft_printf** 要求理解 C 语言中几个核心机制：

1. 可变参数函数（Variadic Functions）。
    
2. 指针与内存管理。
    
3. 字符串解析（Parsing）。
    
4. 数据类型与类型转换。
    
5. 数字进制转换。
    
6. 格式化输出（Formatting）。
    
7. 静态库的创建与使用。
    
8. Makefile 和项目模块化设计。
    

这个项目的核心目标是：

**自己实现一个名为 ft_printf 的函数，模拟 C 标准库 printf 的主要功能

你不能直接调用系统的 `printf` 来完成任务，而是要自己解析格式字符串、读取参数、转换数据并输出字符
