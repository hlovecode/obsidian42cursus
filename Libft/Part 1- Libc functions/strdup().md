strdup() 的作用非常直接，复制一个字符串，并为复制出来的字符串动态分配内存

#### 1. Prototype

```c
char *strdup(const char *s);
```

例如：

```c
char *copy;

copy = strdup("Hello");
```

上面2行代码执行之后，可以理解为：

原来的字符串：

"Hello\0"
   ↑
   s

`strdup()`
   ├── 计算字符串长度
   ├── 申请新的内存
   └── 把 "Hello\0" 复制进去
          ↓

新的动态内存：

┌────┬────┬────┬────┬────┬────┐
│ H  │ e  │ l  │ l  │ o  │ \0 │
└────┴────┴────┴────┴────┴────┘
  ↑
 copy
