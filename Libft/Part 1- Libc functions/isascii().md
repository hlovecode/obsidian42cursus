`isascii()` 和 `isalpha()`、`isdigit()`、`isalnum()` 一样，都属于**字符分类函数**, 不过有一个非常重要的区别：`isascii()` 判断的不是"是不是字母或数字"，而是 "这个字符是不是 ASCII 字符".

#### 1. Prototype

```c
#include <ctype.h>

int isascii(int c);
```
它的作用非常简单，判断参数c是否属于ASCII字符范围.
ASCII 的范围是0 ~ 127 (128个值)，也就是16进制0x00 ~ 0x7F，即：
```txt
0
│
├── 0 ~ 31       控制字符
│
├── 32            空格 ' '
│
├── 33 ~ 47      标点符号
│
├── 48 ~ 57      '0' ~ '9'
│
├── 58 ~ 64      标点符号
│
├── 65 ~ 90      'A' ~ 'Z'
│
├── 91 ~ 96      标点符号
│
├── 97 ~ 122     'a' ~ 'z'
│
├── 123 ~ 126    标点符号
│
└── 127           DEL
```
因此 0<= 参数c <= 127 就是ASCII.

#### 2. ASCII 不等于可打印字符，它还包括大量不可打印字符

```txt
ASCII
  │
  ├── 可打印字符
  │
  └── 不可打印控制字符
```

```txt
             isascii
                │
       ┌────────┴────────┐
       │                 │
      ASCII            非 ASCII
       ├── 字母
       ├── 数字
       ├── 标点
       ├── 空格
       └── 控制字符
```

`isascii()` 经常用于检查一个字符串是否只包含 ASCII 字符, 只需要判断数值是否落在 ASCII 范围内, 即 0 ~ 127.
