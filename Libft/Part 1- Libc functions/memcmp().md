`memcmp` 比较的是两块内存前 `n` 个字节的内容，而不是比较字符串.

#### 1. Prototype

```c
#include <string.h>

int memcmp(const void *s1, const void *s2, size_n);
```

作用是比较从 `s1` 和 `s2` 开始的两块内存区域的前 `n` 个字节

返回值：

|比较结果|`memcmp` 返回值|
|---|---|
|两块内存完全相同|`0`|
|`s1` 中第一个不同字节 **小于** `s2` 中对应字节|小于 `0`|
|`s1` 中第一个不同字节 **大于** `s2` 中对应字节|大于 `0`|

C标准只保证返回值的正负和0， 不保证具体返回多少，也就是说应该做出下面这些判断中的一个,  而不是 ：

```c
if (memcmp(s1, s2, n) > 0)

if (memcmp(s1, s2, n) == 0)

if (memcmp(s1, s2, n) < 0)
```
