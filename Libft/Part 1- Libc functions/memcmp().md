`memcmp` 比较的是两块内存前 `n` 个字节的内容，而不是比较字符串.
把内存看成一串byte, 然后逐个byte比较.

#### 1. Prototype

```c
#include <string.h>

int memcmp(const void *s1, const void *s2, size_n);
```

作用是比较从 `s1` 和 `s2` 开始的两块内存区域的前 `n` 个字节, 即最多比较多少个字节.

返回值：

|比较结果|`memcmp` 返回值|
|---|---|
|两块内存完全相同|`0`|
|`s1` 中第一个不同字节 **小于** `s2` 中对应字节|小于 `0`|
|`s1` 中第一个不同字节 **大于** `s2` 中对应字节|大于 `0`|

C标准只保证返回值的正负和0， 不保证具体返回多少，也就是说应该做出下面这些判断中的一个,  而不是 `memcmp(s1, s2, n) == -1`, 因为C标准没有规定一定返回 -1：

```c
if (memcmp(s1, s2, n) > 0)

if (memcmp(s1, s2, n) == 0)

if (memcmp(s1, s2, n) < 0)
```

#### 2. `memcmp` 比较的是byte

举例：

```c
char a[] = "abc";
char b[] = "abd";
```

内存实际上可以理解为：

```c
a:

address
 ↓
+----+----+----+----+
| a  | b  | c  | \0 |
+----+----+----+----+
 97   98   99    0
 
 
 b:
 
+----+----+----+----+
| a  | b  | d  | \0 |
+----+----+----+----+
 97   98  100    0

```

执行 `memcmp(a, b, 3);` 实际上比较：

```c
first byte: 97 == 97

second byte: 98 == 98

third byte: 99 != 100

```

因为 99 < 100, 因此 `memcmp(a, b, 3) < 0`

#### 3. `memcmp` vs `memcpy` vs `memmove`

| 函数        | 做什么             |
| --------- | --------------- |
| `memset`  | 把一块内存设置成某个 byte |
| `memcpy`  | 把一块内存复制到另一块内存   |
| `memmove` | 安全地移动/复制可能重叠的内存 |
| `memchr`  | 在内存中寻找某个 byte   |
| `memcmp`  | 比较两块内存          |
| `strlen`  | 计算字符串长度         |
| `strcmp`  | 比较字符串           |
