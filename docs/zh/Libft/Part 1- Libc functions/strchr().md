`strchr` 的作用非常简单：在一个字符串中，从头到尾寻找某个字符第一次出现的位置.

#### Prototype

```c
#include <string.h>

char *strchr(const char *s, int c);
```
`strchr` **不是返回字符本身**，而是返回: 
- 找到字符，则返回这个字符在字符串中的**地址** 
- 找不到字符，则返回NULL(0). 

`strchr` 会读取字符串，但不会修改字符串内容.

```
从字符串的第一个字符开始
        ↓
比较当前字符和 c
        ↓
	   相同？
 ┌──────┴──────┐
是             否
↓              ↓
返回当前地址    移动到下一个字符
               ↓
            继续比较
            
直到：
1. 找到目标字符
2. 遇到 `'\0'`
```
